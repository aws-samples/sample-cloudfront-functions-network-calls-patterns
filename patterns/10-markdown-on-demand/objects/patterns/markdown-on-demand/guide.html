Serving markdown to AI agents

Agents read text, not layout. A markdown copy of a page drops the navigation, styles and scripts, so the same content costs the agent far fewer tokens.

How this page becomes markdown

  1. An agent asks for this page. No markdown exists yet, so it gets the HTML.
  2. The CloudFront Function sends the page URI to a queue with cf.beacon.
  3. A worker converts the page, stores guide.md and records it in the KeyValueStore.
  4. The next agent request is served the markdown.

Try it

curl -s -H 'Accept: text/markdown' https://<domain>/patterns/markdown-on-demand/guide.html

Browsers keep getting this HTML page.
